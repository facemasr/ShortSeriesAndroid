# EGYTUBE Keyless Native — 0.4.4 style

Native Android test prototype inspired by EGYTUBE 0.4.4 and using its original icon. Does not request a YouTube Data API key. It is not a binary patch or drop-in update of the original signed v0.4.4 APK. Native search lists and saved library; embedded YouTube player in a dedicated video screen. Unofficial public-search parsing can fail and may not comply with YouTube developer terms; not recommended as a production integration. Debug APK, not verified on a physical Android phone. No background YouTube playback or ad blocking.
