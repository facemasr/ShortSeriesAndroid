# EGYSHOW Native Android

This branch is the **native** Flutter app. It uses EGYSHOW's actual public JSON API, not WebView.

## Verified endpoints
- GET /api/v1/home
- GET /api/v1/media?type=movie|series|short_series&page=1&limit=24
- GET /api/v1/search?q=...
- GET /api/v1/media/:id
- GET /api/v1/live
- GET /api/v1/player/context?target_type=movie|episode|channel&target_id=...
- POST /api/v1/player/source/:sourceId/lease
- POST /api/v1/player/lease/:id/refresh
- POST /api/v1/auth/login and /api/v1/auth/register
- GET /api/v1/profile

## Native features
Flutter Material 3 Arabic and English UI, home rail, multi-page categories, native search,
details, series seasons and episodes, favorites, secure login, live channel directory,
native Android ExoPlayer via video_player, server selection, lease-based playback,
lease refresh for expiring tokens, local resume and watch position, playback speed.

## Notes and limits
- Direct HLS/MP4/DASH sources work when the website's lease API returns Android-compatible
  streams. HTML iframe-only sources are not playable without a separate native relay endpoint.
- Script-based website advertisements are not executed in the native app; native ad integration
  needs dedicated mobile ad formats and configuration.
- Website data and server permissions remain unchanged.
- Real device verification and Google Play signing have not been performed.
- APK is generated by GitHub Actions under the EGYSHOW native workflow.
