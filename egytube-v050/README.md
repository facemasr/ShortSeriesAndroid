# EGYTUBE Native 0.5.1
Original-style EGYTUBE player: Media3 ExoPlayer, not YouTube iframe, original-style quality selector and Auto HLS/DASH where available. The video source extractor is unofficial and not guaranteed to work for every video. Advertisement is in a separate WebView below player. The navigation UI is a separate Android screen. Install is independent from 0.4.4 original, not a same-key upgrade. Debug build, no physical-device validation.
